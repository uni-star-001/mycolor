Privacy Policy

Last updated: June 2026

Core Principle

MyColor does not collect or transmit any user data. All processing happens entirely within your browser.

This Privacy Policy describes how the Chrome extension "MyColor" (the "Extension") handles data.

Data We Store

The Extension only handles the following data:

  • Your color settings per website (text color, background color, etc.)
  • The ON/OFF state of the extension

This data is stored only in your browser (chrome.storage.sync) and is never sent to any external server.

Data We Never Collect

  • URLs or content of websites you visit
  • Personal information (name, email address, etc.)
  • Usage statistics, access logs, or analytics
  • Crash reports or error logs

External Communication

The Extension makes no external network requests. All libraries used (axe-core, chroma.js) are bundled within the extension itself. No content is loaded from CDNs or external sources.

Permissions Requested

  • activeTab: To detect contrast issues on the current page
  • storage: To save your color settings in the browser
  • scripting: To detect and modify elements on the page

No additional permissions are requested.

Data Retention

Stored data can be deleted by uninstalling the extension or using the built-in reset feature. If synced to a Google account, data can also be managed through Google's storage settings.

All of MyColor's code is publicly available on GitHub. You can verify its behavior yourself.

基本方針

MyColorは、ユーザーのデータを一切収集・送信しません。すべての処理はあなたのブラウザ上だけで完結します。

このプライバシーポリシーは、Chrome拡張機能「MyColor」（以下「本ツール」）の利用に関するデータの取り扱いについて説明します。

保存するデータ

本ツールは以下のデータのみを扱います。

  • あなたが設定したサイトごとの色設定（テキスト色・背景色など）
  • 拡張機能のON/OFFの状態

これらのデータは あなたのブラウザ内（chrome.storage.sync）にのみ保存 され、外部のサーバーには一切送信されません。

収集しないデータ

  • 閲覧したWebサイトのURL・コンテンツ
  • 個人を特定できる情報（氏名・メールアドレスなど）
  • 使用状況・アクセスログ・分析データ
  • クラッシュレポートやエラーログ

外部への通信

本ツールは外部サーバーへの通信を一切行いません。使用するライブラリ（axe-core・chroma.js）はすべて拡張機能内に同梱されており、CDNなど外部からの読み込みは行いません。

要求する権限

  • activeTab：現在表示中のページのコントラストを検出するため
  • storage：色設定をブラウザに保存するため
  • scripting：ページ内の要素を検出・変更するため

これ以上の権限は要求しません。

データの保存期間

保存されたデータは、拡張機能をアンインストールするか、設定リセット機能を使用することで削除できます。Googleアカウントに同期している場合は、Googleのストレージ設定からも管理できます。
